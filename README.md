## How I work

- Start with the business problem and constraints, then choose the architecture.
- Treat reliability, authorization, observability, operating cost, and human review as product concerns.
- Prefer explicit trade-offs and measurable validation over architecture for its own sake.
- Keep private source private when needed, but make engineering decisions and outcomes visible through public case studies.
