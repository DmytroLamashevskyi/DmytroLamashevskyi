## How I work

- Start with the problem and the constraint, then choose the architecture.
- Treat reliability, authorization, operating cost, and human review as product concerns.
- Separate what is implemented, deployed, and actually validated.
- Keep private source private when necessary, but make decisions and outcomes legible through public case studies.

Currently focused on validating SchoolAI's narrow homework-review loop, shipping Hollow Way on Android, and turning real engineering work into useful public artifacts.
